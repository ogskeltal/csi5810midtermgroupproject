## Data

The dataset is included in the repository under `dataset/` exactly as downloaded from the UCI Machine Learning
Repository (dataset ID 222, CC BY 4.0, accessed 30 September 2026). If you obtained the code without it:

* Dataset page: <https://archive.ics.uci.edu/dataset/222/bank+marketing>
* Download `bank+marketing.zip`, unzip it, then unzip the inner `bank-additional.zip`.

The notebook expects the file at

```
<repo>/dataset/bank-additional/bank-additional-full.csv
```

i.e. in a `dataset/` folder that sits next to this `code/` folder. Alternatively set the environment
variable `BANK_DATA_PATH` to the full path of `bank-additional-full.csv`.

The notebook uses the *full* file (41,188 rows, 20 inputs, separator `;`). The smaller `bank.zip`
(older 17-attribute version without the macro-economic indicators) is not used.

## Running

```bash
jupyter notebook bank_marketing_midterm.ipynb      # then Kernel -> Restart & Run All
```

or, without opening a browser:

```bash
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 bank_marketing_midterm.ipynb
```

* A full run takes about 10-20 minutes on an 8-core laptop (hyperparameter search for the random forest and
  gradient boosting dominates).
* Set `BANK_FAST=1` in the environment for a 2-3 minute smoke test with tiny hyperparameter grids. Results of a
  fast run are *not* the ones reported.
* All randomness is controlled by `SEED = 5810` (train/test split, cross-validation folds, model seeds,
  randomised search, bootstrap resampling, permutation importance, partial-dependence subsample).

## What the notebook produces

Running all cells regenerates `outputs/figures/*`, `outputs/tables/*` and `outputs/results.json`.
The LaTeX report in `../paper/` includes the `.tex` tables and PDF figures directly from these folders
(they are copied into `../paper/figures` and `../paper/tables` for the Overleaf upload).

## Manual steps / limitations of reproduction

* None of the analysis requires manual steps. The only external dependency is the public UCI download above.
* Multithreaded tree fitting is deterministic for the settings used, so re-running reproduces the reported
  numbers up to floating-point rounding; tiny differences may appear across operating systems or library versions.
